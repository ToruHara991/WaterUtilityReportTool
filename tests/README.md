# 回歸測試

改完程式後跑一次,幾十秒就知道有沒有弄壞既有功能(網頁表格、圖片匯出、PDF、災害模式、離線版)。

## 第一次使用
```
cd tests
npm install
npx playwright install chromium
```

## 日常
```
cd tests
npm test              # 比對基準,全綠才算沒壞
npm run test:dump     # 失敗時把實際輸出寫到 tests/out/ 方便 diff
npm run test:update   # 確定「這次輸出就是該變」時才用,會重建 golden.json
```

## 它測什麼
- **純函式**:時段判斷(含跨年班別)、廠所縮寫、HTML 逸出、時間格式
- **解析**:缺必要欄位的提示、受理編號過短的略過、「供水量案件」別名正規化
- **平常模式 / 災害模式**:排序順序、染色、圖例、網頁表格 HTML、圖片匯出 HTML、PDF 結構
  (每列內容、底色、文字色、欄寬、每頁頁首文字)
- **災害模式 PDF**:每個廠所從新頁開始、單一廠所跨頁續表時每頁都有廠所帶狀列、整列不被分頁線切開
- **統計摘要**:路段判讀、統計數字(手算答案)、預設收合、篩選後同步、位於報告文字上方
- **Excel**:每廠所一分頁、順序、表頭、選填欄/摘要分頁、電話開頭 0、時段篩選、分頁名稱
- **手機寬度(375px)**:摘要展開無橫向捲動、匯出選單不超出螢幕
- **離線版**:封鎖所有外部檔案(CSS/JS/字型,等同單獨一個檔案)時仍可匯出 PDF

## 快照(golden.json)怎麼看
`golden.json` 存的是各輸出內容的雜湊值。快照不同 = 輸出變了。
若是你**刻意**改了版面/顏色,確認新輸出正確後執行 `npm run test:update`,並在 commit 說明裡寫清楚改了什麼。
**欄寬是特調值**:欄寬被改到會讓圖片與 PDF 的快照失敗,這是故意的保護。
